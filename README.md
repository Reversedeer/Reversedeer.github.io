## 本地预览

```bash
git clone https://github.com/Reversedeer/Reversedeer.github.io.git
```
首次使用先安装构建依赖：

```bash
npm install
```
然后：

```bash
npm run build
```
启动服务:

```bash
python -m http.server 8130
```
