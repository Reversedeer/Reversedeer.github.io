URP Tools 课表

课表

按星期和节次展示课程安排，支持 Excel 导出。

查看课表#

在侧栏进入“课表”，首次进入时自动加载本学期课程。“刷新课表”用于重新获取数据。

同一课程有多段上课安排时，会分别显示。缺少星期或节次的记录无法绘制到课表中，页面会显示对应数量。

导出 Excel#

点击“导出本学期课表”，选择保存位置。默认文件名为 本学期课表.xlsx。

导出字段包括课程名称、任课教师、学分、星期、节次、周次、教学楼和教室。选课或退课后，刷新课表再导出即可获得最新记录。

命令行#

主菜单输入 1，程序将课表导出到当前工作目录，并显示完整文件路径。

数据说明#

课表来自教务系统的本学期数据，暂不提供历史学期切换。课程缺失或时间不完整时，可与教务网页核对。
