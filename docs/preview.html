本地预览

一个静态服务就能把三个站走通，直接双击 HTML 也能看。

启动静态服务#

在仓库根目录起一个静态服务，三个站用同一个端口就能访问：

# 在仓库根目录执行
python -m http.server 8130

# 主页   http://127.0.0.1:8130/
# 博客   http://127.0.0.1:8130/blog/
# 文档   http://127.0.0.1:8130/docs/

每个站内部的样式、字体、脚本都是相对路径，直接双击 HTML 用 file:// 打开也能看。跨子域的导航在 HTML 里写的是线上绝对地址；在 localhost、127.0.0.1 或 file:// 下，local-links.js 会自动把它改写成 /blog/、/docs/ 这样的本地路径，所以一个静态服务就能把三个站走通。部署到真实域名时不改写。
