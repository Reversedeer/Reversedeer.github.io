## 解析与登录 {#parse}

| 提示或情况 | 处理 |
| --- | --- |
| 没有找到有效链接 | 输入完整的抖音地址或含链接的分享文本 |
| 目前仅支持抖音链接 | 当前不处理其他平台的地址 |
| 没有读取到可用清晰度 | 确认视频可播放，重新解析；需要时获取 Cookie |
| 登录校验失败 | 先重新解析，连续失败再更新 Cookie |
| HTTP 429 / 请求过于频繁 | 稍后重试，无需立即重新登录 |
| 视频不存在或无法访问 | 核对地址，以及视频的删除、私密和账号访问状态 |

## 清晰度与声音 {#quality}

画质列表来自视频和登录账号实际提供的格式。缺少某个档位时，可以获取 Cookie 后重新解析；选择更高档位不会改变原视频本身的质量。

程序会处理分离的音视频流。下载进度结束后仍显示合并状态时，等待 FFmpeg 完成；出现合并错误时查看日志中的具体信息。

## 下载与文件 {#download}

| 情况 | 处理 |
| --- | --- |
| 所选清晰度已失效 | 重新解析并选择当前可用格式 |
| 网络中断、DNS 或超时 | 检查连接后重试 |
| 无写入权限或空间不足 | 更换保存目录或释放磁盘空间 |
| 下载完成后找不到文件 | 点击“打开文件夹”，或查看“保存位置” |
| 缺少解析或媒体工具 | 源码环境运行 `npm run prepare:binaries`；安装版检查程序是否完整 |

## 反馈问题 {#feedback}

提交版本、视频链接、错误提示和复现步骤即可。Cookie 属于登录凭据，不应附在公开反馈中。
