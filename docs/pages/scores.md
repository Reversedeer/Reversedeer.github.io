## 查询范围 {#views}

进入侧栏“成绩查询”，默认展示本学期成绩。

| 入口 | 内容 |
| --- | --- |
| 本学期成绩 | 当前学期成绩，以及系统返回的最高分、最低分、平均分、名次等信息 |
| 不及格成绩 | 未通过的课程记录 |
| 历年成绩查询 | 历年及格成绩，支持按学年学期筛选 |
| 刷新 | 重新获取当前类别的数据 |

已查询的类别会缓存结果，更新数据使用“刷新”。

## 学期筛选 {#terms}

“历年成绩查询”右侧菜单提供学期列表和“全部”。点击按钮主体，默认展示已加载记录中最新的学期。

历年查询使用的是及格成绩记录，不包含不及格成绩。

## 平均学分绩点 {#gpa}

界面展示累计值和当前学期值，按学分加权计算：

```text
平均学分绩点 = Σ（学分 × 绩点）÷ Σ学分
```

课程属性为“任选”的记录不参与计算，缺少有效学分或绩点的记录会跳过。累计值使用历年及格成绩，当前学期值使用当前展示的记录。计算范围可能与学校的统计口径不同。

## 命令行 {#cli}

主菜单输入 `5`，选择全部及格成绩、不及格成绩或本学期成绩。查询全部及格成绩时，可进一步选择学期；`0` 表示全部。

结果以表格输出，暂不提供成绩 Excel 导出。
