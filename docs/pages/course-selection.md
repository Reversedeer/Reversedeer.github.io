## 选课模式 {#modes}

| 模式 | 行为 |
| --- | --- |
| 普通选课 | 对选中目标执行一次选课流程 |
| 持续抢课 | 重试当前目标，直到成功、达到尝试上限或遇到不可重试的课程错误 |

选课时间、课程余量、资格和时间冲突由教务系统校验。

## 桌面版 {#desktop}

进入“抢课”，点击“刷新课程”获取候选列表。在“任务”列勾选课程，通过右上角 `...` 选择模式，然后点击“提交选中课程”。默认模式为普通选课。

列表显示当前学期、课程、学分、教师、余量、时间和地点。同名课程的不同教学班互斥勾选，不同课程可同时加入任务。

桌面版点击提交后直接执行。多个目标按列表顺序逐个处理；持续模式中，前一个目标结束后才会处理后一个目标。

## 持续抢课参数 {#snatching}

默认不限制尝试次数。设置 `URP_COURSE_SNATCHING_ATTEMPTS` 为正整数可限制尝试次数；并发数和重试间隔见[配置参考](configuration.html#snatching)。

当前桌面版没有独立的停止按钮。命令行任务可通过 `Ctrl+C` 中断。

## 命令行 {#cli}

主菜单输入 `3`，依次选择目标和模式：

1. 输入课程号或 `课程号_课序号` 筛选；直接回车显示全部。
2. 输入候选列表中的序号，`0` 返回。
3. 输入 `yes` 确认。
4. 输入 `1` 普通选课，或 `2` 持续抢课。

课程号筛选属于命令行功能，桌面版直接在表格中勾选。

## 提交结果 {#result}

执行结束后显示各目标的结果，并刷新课程数据。已选课程会从候选列表中移除，可在“退课”或“课表”中查看。

选课未开放时，部分课程仍可预览，但无法提交。持续模式遇到时间冲突、已选课程、阶段结束等错误时会终止当前目标。
