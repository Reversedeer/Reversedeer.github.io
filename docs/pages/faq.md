## 安装与配置 {#setup}

| 情况 | 处理 |
| --- | --- |
| Python 版本不兼容 | 当前要求 Python 3.10；用 `poetry run python --version` 检查运行环境 |
| 桌面程序启动失败 | 源码运行 `poetry run urp-tools-gui` 查看错误输出 |
| 命令行缺少账号密码 | 配置 `URP_USERNAME` 和 `URP_PASSWORD` |
| 配置修改未生效 | 检查配置路径、同名环境变量，并重新启动；详见[配置参考](configuration.html#explicit-file) |

## 登录与会话 {#session}

登录失败时，可用同一账号在教务网页核对登录状态。若网页正常、工具失败，按错误信息区分连接、验证码识别或接口解析问题。

会话失效、异地登录或令牌失效时，程序会尝试恢复认证，侧栏会显示对应状态。恢复失败可退出后重新登录。

## 课程与任务 {#courses}

| 情况 | 说明 |
| --- | --- |
| 可选列表缺少某门课 | 已选课程会被过滤；同时检查学期、选课阶段和课程资格 |
| 能看到课程，不能提交 | 预览不代表选课已开放 |
| 后续任务尚未开始 | 多个目标按顺序处理，持续抢课可能停留在前一个目标 |
| 评教提交前等待 | 默认统一等待 120 秒后提交 |
| 选退课后数据未更新 | 刷新课程列表和课表；执行结果不明确时核对教务网页 |

## 成绩与课表 {#data}

课表只展示本学期。缺少星期或节次的记录不绘制到表格中，导出文件的位置由保存窗口或命令行工作目录决定。

绩点采用学分加权，排除“任选”及无有效学分、绩点的记。

## 问题反馈 {#feedback}

在[项目 Issues](https://github.com/Reversedeer/urp-academic-affairs-tools/issues)提供版本、操作系统、复现步骤和错误信息。截图或日志中的密码、Cookie、令牌等登录凭据应移除。
