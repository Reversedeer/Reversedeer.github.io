抖音视频解析器

解析抖音视频信息，选择清晰度并下载为 MP4。

概览#

抖音视频解析器是一个 Windows 桌面工具，支持粘贴抖音链接或分享文本，读取视频信息并下载。本文档对应 1.0.1 版本。

解析结果包括封面、标题、作者、发布时间、时长及可用清晰度。获取抖音 Cookie 后，可以读取登录状态下提供的画质。

功能#

功能 说明
链接解析 支持抖音短链接、视频链接和包含链接的分享文本，一次解析一条
清晰度选择 显示实际可用的画质、帧率和预计文件大小
登录状态 支持扫码获取 Cookie，也支持手动粘贴
视频下载 保存为 MP4，支持进度显示、取消和打开保存目录

安装与启动#

Windows 安装包为 dy-video-parser-1.0.1-setup.exe，面向 64 位系统。运行安装向导后，从桌面或开始菜单启动“抖音视频解析器”，无需另行安装 Node.js。

首次启动会显示使用说明，倒计时结束后确认进入。源码运行方式见开发与打包。

文档入口#

  • 解析与下载：链接、清晰度、保存位置和任务状态。
  • Cookie 与登录：扫码、手动输入、刷新清晰度及退出登录。
  • 开发与打包：环境要求、启动命令和媒体工具。
  • 常见问题：解析、画质和下载问题。
